## V7 pilot method (reusable pattern)

Before the full 5-year fetch, a 2-month monsoon fetch (~42 min) + a no-training rank
screen (`screen` phase: raw IR lag-1 vs cached gauge/IMERG persistence on identical rows)
gave the go/no-go for ~5% of the download. Pre-registered rule: IR ≥ gauge band
(ROC 0.72–0.79 at h1) → go. IR hit 0.71–0.78. The same screen phase exists in V6 GSMaP.

## Known caveats / open items (state before being asked)

1. **TMD stamp semantics assumed** (stamp t covers hour ending t, available in minutes).
   The offset0→offset1 collapse means one hour of stamp-optimism erases most of the gauge
   gain. Verify against the live TMD feed before shipping.
2. **Provisional IMERG**: everything after 2025-10-01 is Late Run (lower detection);
   deployed model should be recalibrated on that period (V3 runtype breakout shows the
   drop). Labels for the pilot/CV era are mostly permanent.
3. **IR–label affinity**: IMERG ingests geo-IR, so part of the IR gain is grader affinity —
   deployment-relevant (labels ARE IMERG) but worth a sentence in the report.
4. **Not under version control** — the `.git` is empty; the experiment record has asked
   for this since experiment 08.
5. **V8 = deployment wiring**: live feature pipeline (OM API + latest Himawari segment +
   TMD gauges), apply calibrator + threshold from the joblib artifacts.
